# Offline Reading Quiz (Single-user)

## วิธีใช้งาน (ไม่ต้องต่อเน็ต)
1) ดาวน์โหลดไฟล์ zip แล้วแตกไฟล์
2) เปิดโฟลเดอร์ แล้วดับเบิลคลิก `index.html`
3) เลือกจำนวนข้อ + เวลาจับเวลา แล้วกด Start

## แก้/เพิ่มข้อสอบเอง
- เปิดไฟล์ `questions.json`
- แก้ passage และ questions ได้
- รองรับชนิดคำถาม: mcq, classify, insertion, short

## หมายเหตุ
- ระบบนี้บันทึกคำตอบไว้ในเครื่อง (localStorage) เพื่อกลับมาทำต่อได้
- เวอร์ชันนี้เป็น “ต้นแบบใช้งานได้จริงแบบออฟไลน์”
- ถ้าต้องการ “ล็อกอิน/เก็บสถิติ/เก็บผลสอบจริง” จะต่อ Supabase ได้ในขั้นถัดไป
